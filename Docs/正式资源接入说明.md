# 完整第一关资源接入说明

程序已提供占位角色、工位布局与票面接口，当前不需要批量下载模型。

配置入口是 `Assets/Resources/FirstChapter.asset`。修改配置后重新播放；构建工具会保留已有配置，不自动重置美术引用。

## 角色

首批两个角色编号为 zhituan 和 yintao。保持编号不变，否则会影响收藏身份。配置显示名、占位色、Visual Prefab、Animator Controller、Hand Offset。

角色预制体以脚底为原点，正 Z 朝前，1 单位为 1 米。实际移动与碰撞由共用 CharacterController 控制，模型不需要自带刚体或重复的角色碰撞体。动画关闭根运动。

可选动画参数：Speed 为 float，Carrying 和 Working 为 bool。控制器缺少参数时程序不发送对应值。Working 当前反映加工按键与目标选择，正式动作事件仍需逐工位联调，不能把接口存在当成动画已验收。

Hand Offset 调整纸张相对角色根节点的位置。先检查静止、走路、转身时纸张不挡脸，再批量制作动作。

## 工位

Stations 七项顺序为抄纸槽、晾纸 A、晾纸 B、印刷台、盖印台、共享台、交付窗口。数组顺序目前是规则接口，不可随意调换。可改显示名、位置、尺寸、操作点偏移和 Visual Prefab。

Visual Prefab 放到该工位位置，灰盒碰撞和高亮块仍保留作为技术参考；正式模型接入后应检查重复碰撞与遮挡，确认后再隐藏技术块。物件锚点当前由程序生成在台面上方，需要按实际台高联调。

Partitions 控制隔断位置，Spawn Points 控制两人出生点。调整时保留两人会车和工位前操作空间。

## 票面与界面

Ticket Paper 为底纸，Ticket Ink 为双人工匠黑墨图，Ticket Seal 为透明朱印覆盖层。当前第一关只开放纸团和印桃，因此这一组配置只服务一个组合；扩到六角色时再扩展为组合键资源表。

没有图片时，选角、结算和图鉴显示文字占位预览。黑墨和朱印图片需保持同样画布比例，程序可叠加显示；这不代表已完成正式票面的美术排版。

## 联调验收

检查比例、朝向、脚底、根运动、手持遮脸、台高、目标高亮、纸张状态、循环动作及暂停。角色外观导入后需再做双人会车和真实操作验证。第一组通过后再批量接入，不能只凭模型预览图标记完成。
