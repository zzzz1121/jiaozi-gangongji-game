# 双人试玩验收

## 当前边界

自动化规则测试和脚本化回归不能代替真实两人试玩；合作收益、按键冲突、操作舒适度须由两名玩家在同一键盘验证。

## 试玩方法

同一组玩家先完成教学。正式进行两种打法各两轮，每轮 180 秒，轮间重置：

1. 各自从头完成整张票，允许共用工位。
2. 一人备纸，一人印刷交付，允许临时换岗与直接交接。

| 打法/轮次 | 首次交付秒数 | 张数/订单数 | 误交互次数 | 门口受阻 | 等待原因 | 备注 |
|---|---|---|---|---|---|---|
| 各自制作 1 | 待实测 | | | | | |
| 各自制作 2 | 待实测 | | | | | |
| 分工并行 1 | 待实测 | | | | | |
| 分工并行 2 | 待实测 | | | | | |

观察：能否看懂纸张状态，搭档能否接续加工，递交是否误放，是否一方长期等待，分工是否减少往返并提高产量。

## 实际验收勾选

- [ ] 两名玩家连续完成两局，无复制、丢物、卡死或重复结算。
- [ ] 键盘同时移动和操作无按键冲突；必要时记录具体组合。
- [ ] 1280×720、1920×1080、1280×800 下文字和路线清楚。
- [ ] 编辑器与 Windows 构建行为一致。
- [ ] 比较两种打法后确认合作收益；未成立先调布局/耗时，不添加美术掩盖。
